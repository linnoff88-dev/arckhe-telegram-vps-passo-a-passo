Em resumo

É um passo a passo para você montar, na sua própria VPS, um bot de Telegram que passa os seus pedidos para o Claude Code pela sua assinatura. Serve para quem tem um servidor e quer cuidar dele pelo celular sem dar à IA a chave da casa: só você fala com o bot, a IA só lê, e qualquer mudança espera o seu "sim". São 9 etapas, cada uma com o comando, a saída esperada e um Telegram falso para testar. Você precisa de uma VPS Linux com Python 3, do Claude Code logado na sua assinatura e de uma conta no Telegram. Testado no Ubuntu 24.04.

Como funciona

Cinco travas, todas no código

Nenhuma trava depende de a IA "obedecer". Cada uma é uma regra que o programa cumpre, mesmo que a IA erre ou seja enganada por um arquivo.

Você no Telegram→Lista de donos→IA só lê→Proposta conferida→Seu "sim"→Bot executa e anota
1

Porta com lista

Só os números de quem está na lista entram. Lista vazia = ninguém entra; o bot só anota quem tentou.

2

Visita sem mexer em nada

A IA só lê o conteúdo de arquivos dentro da pasta de trabalho. Fora dela, vê só espaço em disco e nomes de pastas e arquivos, nunca o que tem dentro. Chaves, SSH e logins ficam negados.

3

Orçamento antes do serviço

Para mudar algo, a IA só escreve o que faria. O bot confere com uma lista curta de comandos permitidos.

4

Você assina embaixo

Só um "sim" claro libera, e vale por 10 minutos. Quem executa é o bot, exatamente o que mostrou.

5

Caderno de registro

Cada pedido, proposta, "sim" e resultado vira uma linha em auditoria.jsonl, sem o token.

⚠️ O furo que o passo a passo fecha

O Claude Code soma as permissões do seu próprio settings.json (o arquivo de preferências do Claude Code, onde você pode ter liberado comandos para rodar sem perguntar) às do bot. Testamos: numa máquina com rm liberado, o pedido "apague a pasta logs" apagou de verdade, mesmo com o bot pedindo "só leitura". Na etapa 5 o bot passa a ignorar essas configurações (--setting-sources ""), e o teste final coloca uma armadilha dessas de propósito para provar que ela não funciona.

Entre com um usuário comum (não root), instale o Claude Code e faça login com a sua assinatura, não com chave de API. Depois crie a pasta do bot e baixe o Telegram falso.

2

Criar o bot no BotFather e guardar o token

No Telegram, fale com o @BotFather, mande /newbot e guarde o token num .env que só você lê. O token é a senha do bot: nunca vai para git, print ou vídeo. O primeiro bot.py só se apresenta ao Telegram.

O BotFather pede primeiro um nome (qualquer um) e depois um nome de usuário que termine em bot (ex.: minha_vps_bot). No fim, ele entrega o token, no formato 123456789:ABC….

Terminais: cada "terminal" é uma janela (ou aba) com a sua própria conexão SSH na VPS. Para abrir outro, abra uma janela nova e entre de novo por SSH; cada terminal começa com cd ~/kits/telegram-vps-remoto. O cat > .env <<'EOF' … EOF (heredoc) grava no arquivo tudo o que está entre as duas linhas.

    texto = (msg.get("text") or "").strip()

        enviar(chat, f"Você disse: {texto}")

AQUI = os.path.dirname(os.path.abspath(__file__))


def carregar_env(caminho):

API = os.environ.get("TELEGRAM_API", "https://api.telegram.org") + f"/bot{TOKEN}/"   # TELEGRAM_API: só para teste com Telegram falso


def tg(metodo, **dados):

    with urllib.request.urlopen(req, timeout=70) as r:

        tg("sendMessage", chat_id=chat, text=texto[i:i + 3800])


def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:

        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    enviar(chat, f"Você disse: {texto}")

    print(f"no ar · donos={len(DONOS)}", flush=True)

A IA só propõe; o bot confere

A IA passa a responder num formato fixo: a resposta e, se precisar mudar algo, os comandos exatos. O bot confere sem IA:

  • só comandos simples (rm, rmdir, mv, cp, mkdir, touch, gzip, gunzip, tar);
  • só opções de uma lista curta;
  • nenhum caractere que encadeia ou desvia comandos;
  • todo caminho dentro da área.

Como o bot roda os comandos sem shell, curinga (*, ?, [) não funcionaria: o conferidor recusa a proposta ("curinga não funciona aqui…"), e a IA é orientada a citar cada arquivo pelo nome e usar rmdir para a pasta vazia.

def validar(passos):
    """Devolve a lista de comandos (listas de argumentos) ou levanta ValueError dizendo o porquê."""
    if any(c in passos for c in "|;`$<>\n~") or ".." in passos:
        raise ValueError("passos com caractere proibido")
    if any(c in passos for c in "*?["):
        raise ValueError("curinga não funciona aqui (o bot roda sem shell): cite cada arquivo pelo nome")
    cmds = []
    for parte in passos.split("&&"):
        args = shlex.split(parte.strip())
        if not args:
            continue
        if args[0] == "cd" and len(args) == 2 and os.path.realpath(args[1]) == os.path.realpath(AREA):
            continue  # "cd <área>" no começo é inofensivo
        if args[0] not in COMANDOS_OK:
            raise ValueError(f"comando fora da lista: {args[0]}")
        for a in args[1:]:
            if a.startswith("-"):
                # Opção só da lista curta: nada de -C/-t/--directory=... que levam para fora da área.
                if a not in OPCOES_OK.get(args[0], set()):
                    raise ValueError(f"opção não permitida: {a}")
                continue
            real = os.path.realpath(os.path.join(AREA, a))
            if real != os.path.realpath(AREA) and not real.startswith(os.path.realpath(AREA) + os.sep):
                raise ValueError(f"caminho fora da área: {a}")
            if real == os.path.realpath(AREA) and args[0] in ("rm", "mv"):
                raise ValueError("não posso apagar ou mover a própria área")
        cmds.append(args)
    if not cmds:
        raise ValueError("nenhum comando")
    return cmds

        return False

def conferir_tar(args):
    """Antes de extrair, lista o pacote: membro com caminho absoluto, '..' ou link é recusado."""
    if not any(a.startswith("-x") for a in args):
        return
    arq = args[-1]
    p = subprocess.run(["tar", "-tvf", arq], cwd=AREA, capture_output=True, text=True, timeout=60)
    if p.returncode:
        raise ValueError("não consegui listar o pacote")
    for linha in p.stdout.splitlines():
        nome = linha.split(None, 5)[-1] if len(linha.split(None, 5)) == 6 else linha
        if linha[:1] in ("l", "h") or nome.startswith("/") or ".." in nome.split("/"):
            raise ValueError(f"pacote com caminho perigoso: {nome[:80]}")


def executar(cmds):
    saidas = []
    for args in cmds:
        if args[0] == "tar":
            try:
                conferir_tar(args)
            except ValueError as e:
                saidas.append(f"{' '.join(args)} → recusado: {e}")
                break
        p = subprocess.run(args, cwd=AREA, capture_output=True, text=True, timeout=120, env=env_limpo())
        saidas.append(f"{' '.join(args)} → {'ok' if p.returncode == 0 else 'erro: ' + p.stderr.strip()[:200]}")
        if p.returncode:
            break
    return "\n".join(saidas)

def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:
        print(f"recusado: from.id={quem}", flush=True)
        enviar(chat, "Este bot é privado.")
        return
    if not texto:
        return
    if texto == "/start":
        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    p = pendente.get(chat)
    if p and eh_sim(texto):
        pendente.pop(chat)
        if time.time() - p["t"] > PRAZO_OK:
            enviar(chat, "Esse pedido expirou. Peça de novo.")
            return
        r = executar(p["cmds"])
        enviar(chat, "Feito:\n" + r)
        return
    if p:
        pendente.pop(chat)
        palavras = re.sub(r"[^\wáéíóúãõç ]", "", texto.lower()).split()
        if palavras and palavras[0] in ("não", "nao", "n", "cancela", "cancelar", "no"):
            enviar(chat, "Cancelado. Nada foi mudado.")
            return
    tg("sendChatAction", chat_id=chat, action="typing")
    r = claude(texto, LEITURA, ESQUEMA)
    acao = r.get("acao")
    if acao:
        try:
            cmds = validar(acao.get("passos", ""))
        except ValueError as e:
            enviar(chat, f"{r['resposta']}\n\nIsso eu não faço por aqui ({e}). Faça direto no terminal, se for o caso.")
            return
        pendente[chat] = {"acao": acao, "cmds": cmds, "t": time.time()}
        enviar(chat, f"{r['resposta']}\n\nVou fazer: {acao['descricao']}\nComandos: {acao['passos']}\n\nConfirma? (sim/não)")
    else:
        enviar(chat, r["resposta"])

                                   "não", "nao", "cancela", "cancelar", "nunca", "pare", "para")):
        return False   # "sim, mas antes faz backup" não é um sim limpo: cancela e pede de novo
    return palavras[0] in SIM_FORTE or (len(palavras) == 1 and palavras[0] in SIM_SOZINHO)


def conferir_tar(args):
    """Antes de extrair, lista o pacote: membro com caminho absoluto, '..' ou link é recusado."""
    if not any(a.startswith("-x") for a in args):
        return
    arq = args[-1]
    p = subprocess.run(["tar", "-tvf", arq], cwd=AREA, capture_output=True, text=True, timeout=60)
    if p.returncode:
        raise ValueError("não consegui listar o pacote")
    for linha in p.stdout.splitlines():
        nome = linha.split(None, 5)[-1] if len(linha.split(None, 5)) == 6 else linha
        if linha[:1] in ("l", "h") or nome.startswith("/") or ".." in nome.split("/"):
            raise ValueError(f"pacote com caminho perigoso: {nome[:80]}")


def executar(cmds):
    saidas = []
    for args in cmds:
        if args[0] == "tar":
            try:
                conferir_tar(args)
            except ValueError as e:
                saidas.append(f"{' '.join(args)} → recusado: {e}")
                break
        p = subprocess.run(args, cwd=AREA, capture_output=True, text=True, timeout=120, env=env_limpo())
        saidas.append(f"{' '.join(args)} → {'ok' if p.returncode == 0 else 'erro: ' + p.stderr.strip()[:200]}")
        if p.returncode:
            break
    return "\n".join(saidas)

def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:
        auditar(ev="recusado", de=quem, nome=msg.get("from", {}).get("first_name"))
        print(f"recusado: from.id={quem}", flush=True)
        enviar(chat, "Este bot é privado.")
        return
    if not texto:
        return
    if texto == "/start":
        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    p = pendente.get(chat)
    if p and eh_sim(texto):
        pendente.pop(chat)
        if time.time() - p["t"] > PRAZO_OK:
            auditar(ev="expirado", de=quem, acao=p["acao"])
            enviar(chat, "Esse pedido expirou. Peça de novo.")
            return
        auditar(ev="aprovado", de=quem, acao=p["acao"])
        r = executar(p["cmds"])
        auditar(ev="feito", resultado=r[:500])
        enviar(chat, "Feito:\n" + r)
        return
    if p:
        pendente.pop(chat)
        auditar(ev="cancelado", de=quem, texto=texto[:200])
        palavras = re.sub(r"[^\wáéíóúãõç ]", "", texto.lower()).split()
        if palavras and palavras[0] in ("não", "nao", "n", "cancela", "cancelar", "no"):
            enviar(chat, "Cancelado. Nada foi mudado.")
            return
    auditar(ev="pedido", de=quem, texto=texto[:500])
    tg("sendChatAction", chat_id=chat, action="typing")
    r = claude(texto, LEITURA, ESQUEMA)
    acao = r.get("acao")

            cmds = validar(acao.get("passos", ""))

            enviar(chat, f"{r['resposta']}\n\nIsso eu não faço por aqui ({e}). Faça direto no terminal, se for o caso.")
            return
        pendente[chat] = {"acao": acao, "cmds": cmds, "t": time.time()}
        auditar(ev="proposta", acao=acao)
        auditar(ev="resposta", texto=r["resposta"][:500])
        enviar(chat, f"{r['resposta']}\n\nVou fazer: {acao['descricao']}\nComandos: {acao['passos']}\n\nConfirma? (sim/não)")
    else:
        auditar(ev="resposta", texto=r["resposta"][:500])
        enviar(chat, r["resposta"])

Dúvidas

Perguntas comuns

O que costuma aparecer antes de começar.

Preciso saber programar?

Ajuda saber copiar e colar no terminal. O código é dado em cada etapa, com o arquivo pronto para conferir. Se travar, o README tem um pedido pronto para o Claude Code montar junto com você, etapa por etapa.

Custa alguma coisa além da assinatura?

Não. O bot usa o Claude Code que você já assina e só a biblioteca padrão do Python. O Telegram é grátis. Você só precisa de uma VPS.

A IA pode apagar algo sem eu pedir?

Não. Ela só tem ferramentas de leitura: lê conteúdo só dentro da pasta de trabalho e, fora dela, só vê espaço em disco e nomes de pastas e arquivos. Chaves e logins ficam negados. Para mudar algo, ela só escreve a proposta. Quem executa é o bot, depois de um "sim" limpo, e só comandos simples dentro da pasta de trabalho.

E se outra pessoa achar o meu bot?

Ela recebe "Este bot é privado." e o número dela fica anotado. Só os números da lista DONOS conversam com o bot.

Por que montar etapa por etapa, em vez de baixar só o arquivo final?

Porque assim você sabe onde cada trava está e por que ela existe, e pode mudar o bot com segurança (acrescentar um comando, trocar a pasta de trabalho). O arquivo final está na etapa 9, para comparar.

Funciona sem VPS, no meu computador?

Os testes com o Telegram falso rodam em qualquer Linux com Python 3 e Claude Code. O bot de verdade foi feito para ficar ligado numa VPS.
