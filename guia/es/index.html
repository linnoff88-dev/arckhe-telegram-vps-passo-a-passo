Telegram VPS remoto · paso a paso en 9 etapas

Administra tu VPS desde el celular sin entregarle la llave a la IA.

Con Telegram VPS remoto, haces tu pedido en Telegram, Claude Code lo lee y propone, y nada cambia sin tu «sí». Aquí configuras este bot con tus propias manos: cada etapa tiene el código, el comando y la salida que debería aparecer.

En resumen

Esta guía te explica paso a paso cómo configurar, en tu propia VPS, un bot de Telegram que pasa tus pedidos a Claude Code con tu suscripción. Es para quienes tienen un servidor y quieren administrarlo desde el celular sin darle a la IA la llave de la casa: solo tú hablas con el bot, la IA solo lee y cualquier cambio espera tu «sí». Son 9 etapas, cada una con el comando, la salida esperada y un Telegram falso para hacer pruebas. Necesitas una VPS Linux con Python 3, Claude Code con la sesión iniciada usando tu suscripción y una cuenta de Telegram. Probado en Ubuntu 24.04.

El beneficio

No necesitas abrir la laptop, conectarte por SSH y recordar un comando para saber si el disco está lleno. Tampoco necesitas confiar ciegamente en una IA con acceso a la terminal.

Cómo funciona

Cinco barreras, todas en el código

Ninguna barrera depende de que la IA «obedezca». Cada una es una regla que el programa cumple, incluso si la IA se equivoca o un archivo la engaña.

Tú en Telegram→Lista de propietarios→La IA solo lee→Propuesta verificada→Tu «sí»→El bot ejecuta y registra
1

Puerta con lista

Solo se permite el acceso a los números incluidos en la lista. Si está vacía, no entra nadie; el bot solo registra quién lo intentó.

2

Visita sin tocar nada

La IA solo lee el contenido de los archivos dentro de la carpeta de trabajo. Fuera de ella, solo ve el espacio en disco y los nombres de las carpetas y archivos, nunca su contenido. Se bloquea el acceso a claves, SSH e inicios de sesión.

3

Presupuesto antes del trabajo

Para cambiar algo, la IA solo escribe lo que haría. El bot lo verifica con una lista corta de comandos permitidos.

4

Tú das el visto bueno

Solo un «sí» claro lo autoriza, y es válido durante 10 minutos. El bot ejecuta exactamente lo que mostró.

5

Registro de actividad

Cada pedido, propuesta, «sí» y resultado se convierte en una línea de auditoria.jsonl, sin el token.

⚠️ La brecha que corrige esta guía

Claude Code suma los permisos de su propio settings.json (el archivo de preferencias de Claude Code, donde quizá habilitaste comandos para que corran sin preguntar) a los del bot. Lo probamos: en una máquina con rm habilitado, el pedido «borra la carpeta logs» la borró de verdad, aunque el bot pidiera «solo lectura». En la etapa 5, el bot empieza a ignorar esa configuración (--setting-sources ""), y la prueba final coloca a propósito una trampa de ese tipo para demostrar que no funciona.

1

Preparar la VPS y Claude Code

Inicia sesión con un usuario común (no root), instala Claude Code e inicia sesión con tu suscripción, no con una clave de API. Después crea la carpeta del bot y descarga el Telegram falso.

¿Solo tienes el usuario root? Crea un usuario común, entrando como root. Si entras a la VPS con clave SSH, la clave se copia al usuario nuevo; si entras con contraseña, salta la línea del mkdir y usa la contraseña que pida adduser.

ssh maria@IP_DE_LA_VPS

2

Crear el bot en BotFather y guardar el token

En Telegram, habla con @BotFather, envía /newbot y guarda el token en un .env que solo tú puedas leer. El token es la contraseña del bot: nunca va a git, a una captura de pantalla ni a un video. El primer bot.py solo se presenta ante Telegram.

El BotFather pide primero un nombre (cualquiera) y luego un nombre de usuario que termine en bot (ej.: mi_vps_bot). Al final te da el token, con el formato 123456789:ABC….

AQUI = os.path.dirname(os.path.abspath(__file__))


def carregar_env(caminho):
    if os.path.exists(caminho):
        for linha in open(caminho):
            linha = linha.strip()
            if linha and not linha.startswith("#") and "=" in linha:
                k, v = linha.split("=", 1)
                os.environ.setdefault(k.strip(), v.strip())

TOKEN = os.environ.get("TELEGRAM_BOT_TOKEN", "")
API = os.environ.get("TELEGRAM_API", "https://api.telegram.org") + f"/bot{TOKEN}/"   # TELEGRAM_API: só para teste com Telegram falso


def tg(metodo, **dados):
    req = urllib.request.Request(API + metodo, data=urllib.parse.urlencode(dados).encode())
    with urllib.request.urlopen(req, timeout=70) as r:
        return json.load(r)


def enviar(chat, texto):
    for i in range(0, len(texto), 3800):
        tg("sendMessage", chat_id=chat, text=texto[i:i + 3800])

    texto = (msg.get("text") or "").strip()
    if texto:
        enviar(chat, f"Você disse: {texto}")

    if not TOKEN:
        sys.exit("falta TELEGRAM_BOT_TOKEN no .env")
    print("no ar (eco)", flush=True)
    desloc = 0
    while True:
        try:
            up = tg("getUpdates", offset=desloc, timeout=50)
            for u in up.get("result", []):
                desloc = u["update_id"] + 1
                if "message" in u:
                    tratar(u["message"])
        except Exception as e:
            print("rede:", str(e)[:120], flush=True)
            time.sleep(5)


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Etapa 4 — só os DONOS falam com o bot. Lista vazia = ninguém; o bot anota o ID de quem tentou."""
import json, os, sys, time, urllib.parse, urllib.request

AQUI = os.path.dirname(os.path.abspath(__file__))


def carregar_env(caminho):
    if os.path.exists(caminho):
        for linha in open(caminho):
            linha = linha.strip()
            if linha and not linha.startswith("#") and "=" in linha:
                k, v = linha.split("=", 1)
                os.environ.setdefault(k.strip(), v.strip())


carregar_env(os.path.join(AQUI, ".env"))
TOKEN = os.environ.get("TELEGRAM_BOT_TOKEN", "")
DONOS = {int(x) for x in os.environ.get("DONOS", "").replace(" ", "").split(",") if x}
API = os.environ.get("TELEGRAM_API", "https://api.telegram.org") + f"/bot{TOKEN}/"   # TELEGRAM_API: só para teste com Telegram falso


def tg(metodo, **dados):
    req = urllib.request.Request(API + metodo, data=urllib.parse.urlencode(dados).encode())
    with urllib.request.urlopen(req, timeout=70) as r:
        return json.load(r)


def enviar(chat, texto):
    for i in range(0, len(texto), 3800):
        tg("sendMessage", chat_id=chat, text=texto[i:i + 3800])


def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:
        print(f"recusado: from.id={quem}", flush=True)
        enviar(chat, "Este bot é privado.")
        return
    if not texto:
        return
    if texto == "/start":
        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    enviar(chat, f"Você disse: {texto}")


def main():
    if not TOKEN:
        sys.exit("falta TELEGRAM_BOT_TOKEN no .env")
    print(f"no ar · donos={len(DONOS)}", flush=True)
    desloc = 0
    while True:
        try:
            up = tg("getUpdates", offset=desloc, timeout=50)
            for u in up.get("result", []):
                desloc = u["update_id"] + 1
                if "message" in u:
                    tratar(u["message"])
        except Exception as e:
            print("rede:", str(e)[:120], flush=True)
            time.sleep(5)


if __name__ == "__main__":
    main()

La IA solo propone; el bot verifica

La IA empieza a responder en un formato fijo: la respuesta y, si hace falta cambiar algo, los comandos exactos. El bot lo verifica sin IA:

  • solo comandos simples (rm, rmdir, mv, cp, mkdir, touch, gzip, gunzip, tar);

def validar(passos):
    """Devolve a lista de comandos (listas de argumentos) ou levanta ValueError dizendo o porquê."""
    if any(c in passos for c in "|;`$<>\n~") or ".." in passos:
        raise ValueError("passos com caractere proibido")
    if any(c in passos for c in "*?["):
        raise ValueError("curinga nêo funciona aqui (o bot roda sem shell): cite cada arquivo pelo nome")
    cmds = []
    for parte in passos.split("&&"):
        args = shlex.split(parte.strip())
        if not args:
            continue
        if args[0] == "cd" and len(args) == 2 and os.path.realpath(args[1]) == os.path.realpath(AREA):
            continue  # "cd <área>" no começo é inofensivo
        if args[0] not in COMANDOS_OK:
            raise ValueError(f"comando fora da lista: {args[0]}")
        for a in args[1:]:
            if a.startswith("-"):
                # Opçêo só da lista curta: nada de -C/-t/--directory=... que levam para fora da área.
                if a not in OPCOES_OK.get(args[0], set()):
                    raise ValueError(f"opçêo nêo permitida: {a}")
                continue
            real = os.path.realpath(os.path.join(AREA, a))
            if real != os.path.realpath(AREA) and not real.startswith(os.path.realpath(AREA) + os.sep):
                raise ValueError(f"caminho fora da área: {a}")
            if real == os.path.realpath(AREA) and args[0] in ("rm", "mv"):
                raise ValueError("nêo posso apagar ou mover a própria área")
        cmds.append(args)
    if not cmds:
        raise ValueError("nenhum comando")
    return cmds

def validar(passos):
    """Devolve a lista de comandos (listas de argumentos) ou levanta ValueError dizendo o porquê."""
    if any(c in passos for c in "|;`$<>\n~") or ".." in passos:
        raise ValueError("passos com caractere proibido")
    if any(c in passos for c in "*?["):
        raise ValueError("curinga nêo funciona aqui (o bot roda sem shell): cite cada arquivo pelo nome")
    cmds = []
    for parte in passos.split("&&"):
        args = shlex.split(parte.strip())
        if not args:
            continue
        if args[0] == "cd" and len(args) == 2 and os.path.realpath(args[1]) == os.path.realpath(AREA):
            continue  # "cd <área>" no começo é inofensivo
        if args[0] not in COMANDOS_OK:
            raise ValueError(f"comando fora da lista: {args[0]}")
        for a in args[1:]:
            if a.startswith("-"):
                # Opçêo só da lista curta: nada de -C/-t/--directory=... que levam para fora da área.
                if a not in OPCOES_OK.get(args[0], set()):
                    raise ValueError(f"opçêo nêo permitida: {a}")
                continue
            real = os.path.realpath(os.path.join(AREA, a))
            if real != os.path.realpath(AREA) and not real.startswith(os.path.realpath(AREA) + os.sep):
                raise ValueError(f"caminho fora da área: {a}")
            if real == os.path.realpath(AREA) and args[0] in ("rm", "mv"):
                raise ValueError("nêo posso apagar ou mover a própria área")
        cmds.append(args)
    if not cmds:
        raise ValueError("nenhum comando")
    return cmds


def eh_sim(texto):
    """'sim', 'sim, pode apagar' e 'pode' confirmam; 'pode listar antes?' e 'faz um backup primeiro' nêo."""
    if "?" in texto:
        return False
    palavras = re.sub(r"[^\wáéíóúêõç ]", "", texto.lower()).split()
    if not palavras:
        return False
    if any(w in ("no", "not") for w in (palavras[0], palavras[1:2] and palavras[1], palavras[-1])):
        return False   # "no" só cancela no começo: em português "no" também é "em + o" ("sim, apaga o que está no log")
    if any(w in palavras for w in ("mas", "pero", "but", "antes", "primeiro", "depois", "espera",
                                   "nêo", "nao", "cancela", "cancelar", "nunca", "pare", "para")):
        return False   # "sim, mas antes faz backup" nêo é um sim limpo: cancela e pede de novo
    return palavras[0] in SIM_FORTE or (len(palavras) == 1 and palavras[0] in SIM_SOZINHO)


def conferir_tar(args):
    """Antes de extrair, lista o pacote: membro com caminho absoluto, '..' ou link é recusado."""
    if not any(a.startswith("-x") for a in args):
        return
    arq = args[-1]
    p = subprocess.run(["tar", "-tvf", arq], cwd=AREA, capture_output=True, text=True, timeout=60)
    if p.returncode:
        raise ValueError("nêo consegui listar o pacote")
    for linha in p.stdout.splitlines():
        nome = linha.split(None, 5)[-1] if len(linha.split(None, 5)) == 6 else linha
        if linha[:1] in ("l", "h") or nome.startswith("/") or ".." in nome.split("/"):
            raise ValueError(f"pacote com caminho perigoso: {nome[:80]}")


def executar(cmds):
    saidas = []
    for args in cmds:
        if args[0] == "tar":
            try:
                conferir_tar(args)
            except ValueError as e:
                saidas.append(f"{' '.join(args)} → recusado: {e}")
                break
        p = subprocess.run(args, cwd=AREA, capture_output=True, text=True, timeout=120, env=env_limpo())
        saidas.append(f"{' '.join(args)} → {'ok' if p.returncode == 0 else 'erro: ' + p.stderr.strip()[:200]}")
        if p.returncode:
            break
    return "\n".join(saidas)

def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:
        print(f"recusado: from.id={quem}", flush=True)
        enviar(chat, "Este bot é privado.")
        return
    if not texto:
        return
    if texto == "/start":
        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    p = pendente.get(chat)
    if p and eh_sim(texto):
        pendente.pop(chat)
        if time.time() - p["t"] > PRAZO_OK:
            enviar(chat, "Esse pedido expirou. Peça de novo.")
            return
        r = executar(p["cmds"])
        enviar(chat, "Feito:\n" + r)
        return
    if p:
        pendente.pop(chat)
        palavras = re.sub(r"[^\wáéíóúêõç ]", "", texto.lower()).split()
        if palavras and palavras[0] in ("nêo", "nao", "n", "cancela", "cancelar", "no"):
            enviar(chat, "Cancelado. Nada foi mudado.")
            return
    tg("sendChatAction", chat_id=chat, action="typing")
    r = claude(texto, LEITURA, ESQUEMA)
    acao = r.get("acao")
    if acao:
        try:
            cmds = validar(acao.get("passos", ""))
        except ValueError as e:
            enviar(chat, f"{r['resposta']}\n\nIsso eu nêo faço por aqui ({e}). Faça direto no terminal, se for o caso.")
            return
        pendente[chat] = {"acao": acao, "cmds": cmds, "t": time.time()}
        enviar(chat, f"{r['resposta']}\n\nVou fazer: {acao['descricao']}\nComandos: {acao['passos']}\n\nConfirma? (sim/nêo)")
    else:
        enviar(chat, r["resposta"])

    if any(c in passos for c in "|;`$<>\n~") or ".." in passos:
        raise ValueError("passos com caractere proibido")
    if any(c in passos for c in "*?["):
        raise ValueError("curinga nêo funciona aqui (o bot roda sem shell): cite cada arquivo pelo nome")
    cmds = []
    for parte in passos.split("&&"):
        args = shlex.split(parte.strip())
        if not args:
            continue
        if args[0] == "cd" and len(args) == 2 and os.path.realpath(args[1]) == os.path.realpath(AREA):
            continue  # "cd <área>" no começo é inofensivo
        if args[0] not in COMANDOS_OK:
            raise ValueError(f"comando fora da lista: {args[0]}")
        for a in args[1:]:
            if a.startswith("-"):
                # Opçêo só da lista curta: nada de -C/-t/--directory=... que levam para fora da área.
                if a not in OPCOES_OK.get(args[0], set()):
                    raise ValueError(f"opçêo nêo permitida: {a}")
                continue
            real = os.path.realpath(os.path.join(AREA, a))
            if real != os.path.realpath(AREA) and not real.startswith(os.path.realpath(AREA) + os.sep):
                raise ValueError(f"caminho fora da área: {a}")
            if real == os.path.realpath(AREA) and args[0] in ("rm", "mv"):
                raise ValueError("nêo posso apagar ou mover a própria área")
        cmds.append(args)
    if not cmds:
        raise ValueError("nenhum comando")
    return cmds


def eh_sim(texto):
    """'sim', 'sim, pode apagar' e 'pode' confirmam; 'pode listar antes?' e 'faz um backup primeiro' nêo."""
    if "?" in texto:
        return False
    palavras = re.sub(r"[^\wáéíóúêõç ]", "", texto.lower()).split()
    if not palavras:
        return False
    if any(w in ("no", "not") for w in (palavras[0], palavras[1:2] and palavras[1], palavras[-1])):
        return False   # "no" só cancela no começo: em português "no" também é "em + o" ("sim, apaga o que está no log")
    if any(w in palavras for w in ("mas", "pero", "but", "antes", "primeiro", "depois", "espera",
                                   "nêo", "nao", "cancela", "cancelar", "nunca", "pare", "para")):
        return False   # "sim, mas antes faz backup" nêo é um sim limpo: cancela e pede de novo
    return palavras[0] in SIM_FORTE or (len(palavras) == 1 and palavras[0] in SIM_SOZINHO)


def conferir_tar(args):
    """Antes de extrair, lista o pacote: membro com caminho absoluto, '..' ou link é recusado."""
    if not any(a.startswith("-x") for a in args):
        return
    arq = args[-1]
    p = subprocess.run(["tar", "-tvf", arq], cwd=AREA, capture_output=True, text=True, timeout=60)
    if p.returncode:
        raise ValueError("nêo consegui listar o pacote")
    for linha in p.stdout.splitlines():
        nome = linha.split(None, 5)[-1] if len(linha.split(None, 5)) == 6 else linha
        if linha[:1] in ("l", "h") or nome.startswith("/") or ".." in nome.split("/"):
            raise ValueError(f"pacote com caminho perigoso: {nome[:80]}")


def executar(cmds):
    saidas = []
    for args in cmds:
        if args[0] == "tar":
            try:
                conferir_tar(args)
            except ValueError as e:
                saidas.append(f"{' '.join(args)} → recusado: {e}")
                break
        p = subprocess.run(args, cwd=AREA, capture_output=True, text=True, timeout=120, env=env_limpo())
        saidas.append(f"{' '.join(args)} → {'ok' if p.returncode == 0 else 'erro: ' + p.stderr.strip()[:200]}")
        if p.returncode:
            break
    return "\n".join(saidas)

def tratar(msg):
    chat, quem = msg["chat"]["id"], msg.get("from", {}).get("id")
    texto = (msg.get("text") or "").strip()
    if quem not in DONOS:
        auditar(ev="recusado", de=quem, nome=msg.get("from", {}).get("first_name"))
        print(f"recusado: from.id={quem}", flush=True)
        enviar(chat, "Este bot é privado.")
        return
    if not texto:
        return
    if texto == "/start":
        enviar(chat, "Pronto. Peça o que quiser na VPS. Antes de mudar qualquer coisa eu pergunto.")
        return
    p = pendente.get(chat)
    if p and eh_sim(texto):
        pendente.pop(chat)
        if time.time() - p["t"] > PRAZO_OK:
            auditar(ev="expirado", de=quem, acao=p["acao"])
            enviar(chat, "Esse pedido expirou. Peça de novo.")
            return
        auditar(ev="aprovado", de=quem, acao=p["acao"])
        r = executar(p["cmds"])
        auditar(ev="feito", resultado=r[:500])
        enviar(chat, "Feito:\n" + r)
        return
    if p:
        pendente.pop(chat)
        auditar(ev="cancelado", de=quem, texto=texto[:200])
        palavras = re.sub(r"[^\wáéíóúêõç ]", "", texto.lower()).split()
        if palavras and palavras[0] in ("nêo", "nao", "n", "cancela", "cancelar", "no"):
            enviar(chat, "Cancelado. Nada foi mudado.")
            return
    auditar(ev="pedido", de=quem, texto=texto[:500])
    tg("sendChatAction", chat_id=chat, action="typing")
    r = claude(texto, LEITURA, ESQUEMA)
    acao = r.get("acao")
    if acao:
        try:
            cmds = validar(acao.get("passos", ""))
        except ValueError as e:
            auditar(ev="proposta_recusada", acao=acao, motivo=str(e))
            enviar(chat, f"{r['resposta']}\n\nIsso eu nêo faço por aqui ({e}). Faça direto no terminal, se for o caso.")
            return
        pendente[chat] = {"acao": acao, "cmds": cmds, "t": time.time()}
        auditar(ev="proposta", acao=acao)
        auditar(ev="resposta", texto=r["resposta"][:500])
        enviar(chat, f"{r['resposta']}\n\nVou fazer: {acao['descricao']}\nComandos: {acao['passos']}\n\nConfirma? (sim/nêo)")
    else:
        auditar(ev="resposta", texto=r["resposta"][:500])
        enviar(chat, r["resposta"])

¿Necesito saber programar?

Ayuda saber copiar y pegar en la terminal. El código está incluido en cada etapa, junto con el archivo listo para que lo revises. Si te atascas, el README tiene un pedido listo para que Claude Code lo construya contigo, etapa por etapa.

¿Cuesta algo además de la suscripción?

No. El bot usa Claude Code, que ya tienes con tu suscripción, y solo la biblioteca estándar de Python. Telegram es gratis. Solo necesitas una VPS.

¿La IA puede borrar algo sin que se lo pida?

No. Solo tiene herramientas de lectura: lee contenido únicamente dentro de la carpeta de trabajo y, fuera de ella, solo ve el espacio en disco y los nombres de las carpetas y archivos. Se bloquea el acceso a claves e inicios de sesión. Para cambiar algo, solo escribe la propuesta. El bot lo ejecuta después de un «sí» claro y con comandos simples dentro de la carpeta de trabajo.

¿Y si otra persona encuentra mi bot?

Recibe «Este bot es privado.» y su número queda registrado. Solo los números de la lista DONOS pueden hablar con el bot.

¿Por qué montarlo etapa por etapa en vez de bajar solo el archivo final?

Porque así sabes dónde está cada protección y por qué existe, y puedes cambiar el bot con seguridad (añadir un comando, cambiar la carpeta de trabajo). El archivo final está en la etapa 9, para comparar.
